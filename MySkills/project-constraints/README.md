# 项目专项约束注册目录

> 本目录是项目级专项约束包的**固定注册面**。
> 由 `workflow/constraints` 维护；后续由主智能体按任务匹配后装载到 HR、并行技能或当前执行上下文中。

## 当前状态

当前尚无已注册的专项约束包。

这不是普通空目录，而是表示：

- 专项约束层已经建立
- 固定索引文件已经存在
- 用户后续可以继续把行业规范、项目命名约定、模块规则或专项技能草稿接进这里
- 在出现真实约束包前，主智能体应显式说明“当前无专项约束包生效”

## 目录约定

```text
MySkills/project-constraints/
├── README.md               ← 本文件（固定索引）
└── *.md                    ← 专项约束包
```

## 约束包最小字段

后续新增的每个约束包文档，建议至少写清：

- 名称
- 类型（行业 / 项目 / 命名 / 模块 / 其他）
- 适用任务
- 适用角色
- 适用文件范围
- 装载模式（默认 / 必须 / 可选）
- 来源材料
- 当前状态（草稿 / 已注册 / 停用）

## 注册约定

1. 约束包由 `workflow/constraints` 统一登记或更新。
2. 主智能体后续应优先读取本索引，再决定本轮需要装载哪些专项约束。
3. 子智能体不应自行扫描本目录猜测规则。
4. 若目录下只有本文件，等价于“专项约束层已建立，但当前无可装载约束包”。
